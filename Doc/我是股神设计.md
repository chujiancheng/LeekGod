# 目录说明
Client 客户端目录，用h5
Server 服务端目录，语言用nodejs

# 简介
这是一个炒股模拟的游戏，玩家在里面操作股票的买卖来获利。股票交易方式需要模拟真实股票交易的模式，可以参考国内股票交易所的股票交易规则。

# 账号功能
玩家输入账号即可登录，不需要密码。账号信息暂时都存在内存中。

# 交易功能
模拟真实股票交易，客户端需要看到实时的盘面，玩家有一定的初始资金，可以选择做多或者做空。交易数据也暂时存在内存
手续费先按万分之一来
需要限制玩家的交易频率不可过快
买入的股票可以有个冻结时间不能卖出，类似T+1,但是我们这边可以设置为x分钟，x可供配置，先按5分钟处理
要设计npc，npc有机构和散户
可以设计随机的消息利空或者利多，消息会对npc起作用决定买入或者卖出。
