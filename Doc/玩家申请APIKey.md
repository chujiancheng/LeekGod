# 我是股神 · 开放平台入门（玩家版）

> 这份文档是给**玩家**看的，不含任何服务器运维内容。
> 你要做三件事：**登录游戏 → 在开放平台页点一下生成 Key → 自检**。
> 全程两分钟，不需要找管理员，也不需要懂服务器。

---

## 0. 一句话版

登录游戏 → 主页点「**开放接口**」→ 填个备注、选权限 → 点「**生成 Key**」→ 复制弹层里的
`gs_...` → 存进环境变量 → 跑一次自检 → 开始写策略。

生成、查看、撤销都在网页上自己完成，**不需要私聊管理员**。

文档也可以直接在网页上看：

- 阅读：`/docs.html?doc=player`（本页）· `/docs.html?doc=api`（接口完全手册）
- 下载：`/docs/player-apikey.md?download=1` · `/docs/openapi.md?download=1`

---

## 1. 开放接口是什么

| 是 | 不是 |
|---|---|
| 一个 HTTP 接口，让你**在自己电脑上**跑 Python / Node 策略 | 不是网页里写代码、也不是把代码上传给服务器跑 |
| 和你手动点鼠标**完全同一套规则**：同样的冷却、费率、锁仓、涨跌停 | 不是"量化特权通道"，不会让你下单更快、费率更低 |
| 只操作**你自己账号**的委托和持仓 | 看不到别人的持仓，也看不到服务器的底牌（公允价、主力意图等） |
| 一台机器一把 Key，可单独撤销 | 不是共享账号，不要把你的 Key 发给别人 |

**公平性说明**：接口只是替你点了鼠标。下单冷却（默认 2 秒、跨股票共享）、买入后 T+10 秒才能卖、整手、涨跌停、保证金，一条都不会少。所以"用接口能不能赢"取决于你的规则，不取决于接口。

---

## 2. 你能用它做什么

- **自动交易**：均线、网格、突破、套利，按你自己的信号下单撤单。
- **盯盘提醒**：轮询行情，触发条件时推送到你的手机 / 群里。
- **批量对账**：把自己的成交、持仓导出来做分析。
- **多标的监控**：一次拿全市场行情（10 只股票 + 指数），不用一个个点。

不能做的：上传策略代码让服务器代跑、提高下单频率上限、读取内幕字段、操作其他玩家账号。

## 3. 进页面前：确认两件事

### 3.1 你已经在游戏里登录

开放平台页用的是你的**游戏登录状态**，所以 Key 一定绑在你自己的账号上，不会签给别人。

用浏览器打开游戏主页，登录进去（如果已经在玩，直接点主页的「**开放接口**」按钮）。

### 3.2 你已经"开完户"

开户 = **有昵称 + 选过券商**，两者缺一都不算。新号第一次进游戏会让你补这两样。

没开完户也能进页面，但点「生成 Key」会提示：

```
还没走完开户（缺昵称或券商），先回主页补完再来
```

花一分钟选个券商就好，这一步只做一次。

## 4. 生成一把 Key

### 4.1 页面在哪

两个入口，效果一样：

- 游戏主页 → 按钮区里的「**开放接口**」
- 直接访问 `服务器地址/portal.html`，例如 `http://1.2.3.4:3000/portal.html`

页头会显示 `账号 xxx · 已登录`。如果显示「未登录」，点页面里的「回主页登录」。

### 4.2 填两个东西

| 字段 | 怎么填 | 说明 |
|---|---|---|
| **备注** | 一句话，例如「家用电脑-双均线」「云主机-网格」 | 只给你自己看，用来区分多把 Key；不填也行 |
| **权限** | `read,trade`（默认，可下单）或 `read`（只看行情和账户） | 不确定就先选 `read` 跑通链路，再生成一把 `read,trade` |

### 4.3 点「生成 Key」

页面会弹出一个窗口，中间是一串 `gs_` 开头的完整 Key：

```
gs_3f2a9c1e_Bt8xQ2mN7vR4kL9pS1wY6zA0cE5hJ3dF
```

**这是你唯一一次看到明文。** 服务器只存它的哈希，连管理员都看不到，关掉窗口后没有任何地方能再查。

窗口里两个按钮：

- 「**复制 Key**」：复制到剪贴板，提示「已复制，去存进环境变量」；
- 「**我已保存**」：关窗口。

> 复制失败（比如浏览器限制了剪贴板）时，手动选中那串文字复制，效果一样。

### 4.4 生成的 Key 长什么样

`gs_` + 8 位十六进制 **KeyID** + `_` + 32 位随机串：

```
gs_  3f2a9c1e  _  Bt8xQ2mN7vR4kL9pS1wY6zA0cE5hJ3dF
    └ KeyID ┘     └────────── 秘密部分 ──────────┘
```

- **KeyID**（`3f2a9c1e`）可以公开、可以贴日志、可以在群里说，它不能用来调用接口；
- **整串 Key** 是凭据，等于你账户的操作权，**只放环境变量或本地配置文件**。

## 5. 页面上还能做什么

「我的 Key」表格列出你所有**有效**的 Key：

| 列 | 含义 |
|---|---|
| KeyID | 8 位十六进制，撤销和排查时用它 |
| 备注 | 你生成时填的那句话 |
| 权限 | `read` 或 `read,trade` |
| 创建 | 生成时间 |
| 最近使用 | 服务端记录的最近一次调用时间；显示「从未」说明这把还没用过 |

右上角显示 `2 / 8 把` 这样的配额。

**撤销**：点那一行的「撤销」→ 确认 → **立即生效**。正在跑的策略下一次请求就会收到 `401`，已经建立的推送连接会断开重连失败。撤销不可恢复，但你可以马上生成新的。

**上限**：一个账号最多 **8 把有效 Key**。到上限时页面会提示 `最多 8 把有效 Key，先撤销不用的再申请`。

**不会过期**：Key 没有有效期，只有你主动撤销才失效。所以"临时用一下"也建议用完就撤。

## 6. 拿到后：三步自检（约 2 分钟）

页面底部「拿到 Key 之后」已经把命令按你的服务器地址拼好了，直接复制即可。下面是解释。

### 第一步：把 Key 存进环境变量

Linux / macOS：

```bash
export GUSHEN_API_KEY='gs_3f2a9c1e_Bt8x...'
export GUSHEN_BASE='http://1.2.3.4:3000'
```

Windows CMD：

```bat
set GUSHEN_API_KEY=gs_3f2a9c1e_Bt8x...
set GUSHEN_BASE=http://1.2.3.4:3000
```

PowerShell：

```powershell
$env:GUSHEN_API_KEY = 'gs_3f2a9c1e_Bt8x...'
$env:GUSHEN_BASE = 'http://1.2.3.4:3000'
```

**不要**把 Key 直接写进代码里，也不要提交到 git。想持久化就写进 `~/.bashrc` / `~/.zshrc`，
或 Windows 的"系统属性 → 环境变量"。注意别写进会同步到云端的笔记里。

`GUSHEN_BASE` 就是你打开开放平台页用的那个地址（页面底部会直接给出，照抄）。

### 第二步：探活

```bash
curl -s -H "X-API-Key: $GUSHEN_API_KEY" $GUSHEN_BASE/open/v1/ping
```

正常返回：

```json
{
  "ok": true,
  "account": "quant_a",
  "nick": "量化甲",
  "keyId": "3f2a9c1e",
  "scopes": "read,trade",
  "seq": 18422,
  "serverTime": 1792300000000,
  "cooldownLeftMs": 0
}
```

看到 `ok: true` 就成功了。三项都要对：

- `account` 是你自己的账号（不是别人的）；
- `scopes` 和你生成时选的权限一致；
- `cooldownLeftMs` 是当前冷却剩余毫秒，`0` 表示现在能下单。

### 第三步：确认能看到自己的账户

```bash
curl -s -H "X-API-Key: $GUSHEN_API_KEY" $GUSHEN_BASE/open/v1/account
```

返回里应该有你熟悉的现金和持仓。如果 `cash` 和你记忆里的对不上，先别下单——大概率是登错了账号，回页面确认 `ping` 里的 `account`。

### 自检结果对照

| 你看到 | 含义 | 怎么办 |
|---|---|---|
| `200` + `ok: true` | 一切正常 | 继续写策略 |
| `401` + `unauthorized` | Key 错了 / 已撤销 / 复制时少了字符 | 检查是否漏了 `gs_` 前缀或末尾字符；仍不行就回页面重新生成 |
| `403` + `该 Key 没有 trade 权限` | 你生成的是只读 Key | 正常保护，需要下单就再生成一把 `read,trade` |
| `429` + `rate_limited` | 请求太密（读 240 次/分钟，交易 60 次/分钟） | 降低轮询频率，见 §8 |
| 连不上 / 超时 | 地址或端口错，或服务没开 | 用你打开开放平台页的那个地址，别改成 `127.0.0.1` |

## 7. 安全规则

| 规则 | 原因 |
|---|---|
| Key 只放环境变量或本地配置文件 | 代码会进 git、会被分享，Key 跟着泄露 |
| 一台机器 / 一个策略一把 Key | 出问题只撤销那一把，不影响其他策略 |
| 不共用、不转借 | 别人用你的 Key 下单，亏的是你的钱，记录也记在你头上 |
| 只读用途就生成 `read` | 少一个权限少一份风险 |
| 定期看「最近使用」列 | 你没在跑策略却有调用时间 = 可能已经泄露 |
| 怀疑泄露立刻点「撤销」 | 撤销是**立即生效**的，下一毫秒就 `401` |

**最容易泄露的四个动作**：把 Key 贴进公开仓库、发到群里问"这个怎么用"、录屏时把终端一起录进去、把 Key 硬编码进前端 JS。

## 8. 使用规范（不遵守会被限流，不是封号）

| 项目 | 限额 | 说明 |
|---|---|---|
| 读接口 | 240 次/分钟/Key | 行情、账户、委托、成交都算；一次 `/markets` 已经包含全市场，不要按股票循环 |
| 交易接口 | 60 次/分钟/Key | 下单 + 撤单合计 |
| IP 兜底 | 1200 次/分钟/IP | 同一出口 IP 下所有 Key 合计 |
| 行情推送 | 2 条连接/Key | 用 SSE 就不需要高频轮询 |

**重要**：撮合是 **700ms 一个 tick**，你 100ms 轮询一次并不会更快，只会浪费配额。合理的轮询间隔是 **1~3 秒**；要更实时就用 `/open/v1/stream` 推送。

下单频率的真正上限是**账户冷却**（默认 2 秒，券商可能不同），不是网络快慢。策略里请读 `/meta` 的 `rules.cooldownMs`，不要写死。

## 9. 换机、多策略、泄露怎么办

全部在页面上自己处理，不用找管理员。

| 场景 | 怎么做 | 旧 Key 要撤销吗 |
|---|---|---|
| Key 丢了 / 复制不全 | 重新生成一把，备注写清用途 | 旧的那把你看不到了，顺手撤销更干净 |
| 换电脑 | 新机器直接重新生成一把 | 建议撤销旧的：老机器的 shell 历史和配置里可能还留着 |
| 一个账号跑多个策略 | 一个策略生成一把，备注区分（如「网格-600001」） | 停用某个策略时只撤销那一把 |
| 只想看盘不下单 | 生成时选 `read` | — |
| 账号改了昵称 / 换了券商 | **不影响 Key**，继续用 | 不用 |
| 服务器重启 / 游戏更新 | **不影响 Key**，存在数据库里 | 不用 |
| 怀疑被别人用了 | 立刻撤销 + 重新生成，再去游戏里核对委托和持仓 | 必须 |
| 到 8 把上限了 | 撤销不用的 | — |

## 10. 生成失败的情况

| 页面提示 | 原因 | 怎么解决 |
|---|---|---|
| `请先登录` / 页头显示「未登录」 | 登录态过期或换了浏览器 | 回主页重新登录，再点「开放接口」 |
| `还没走完开户（缺昵称或券商），先回主页补完再来` | 没选券商或没设昵称 | 进游戏补完，再回来 |
| `最多 8 把有效 Key，先撤销不用的再申请` | 旧 Key 没清理 | 在「我的 Key」里撤销 |
| `开放接口已关闭` | 运维临时关了开放接口 | 找管理员确认开放时间 |
| `请求过于频繁，请稍后再试` | 短时间内反复点 | 等几秒再点 |

## 11. 常见问题

**Q：Key 会过期吗？**
不会。只有你自己点「撤销」才失效。

**Q：管理员能看到我的 Key 吗？**
不能。服务器只存哈希，页面上那一次弹层就是明文唯一出现的地方。丢了只能撤销重发。

**Q：能找回上次生成的 Key 吗？**
不能，任何人都不行。这是故意的设计：能找回就说明服务器存了明文，泄露风险大得多。

**Q：能在两台机器上同时用同一把 Key 吗？**
技术上可以，但不建议：两台机器共享同一个账户冷却和限流，会互相抢；出问题也分不清是谁下的单。请一台机器一把。

**Q：重启游戏、服务器维护后要重新生成吗？**
不用。Key 存在数据库里，重启不丢。

**Q：别人知道我的账号名，能替我生成 Key 吗？**
不能。生成 Key 需要**你的登录会话**，页面只给当前登录的账号签发，而且只能看到、撤销自己的 Key。别人的 Key 在页面上根本不会出现。

**Q：我能用接口看到别人的持仓 / 主力意图 / 公允价吗？**
不能。接口只返回公开行情和你自己的账户。服务器的内部字段（公允价、资金流强度、战术意图、LLM 计划）一律不下发，这是设计上的红线，不是权限没给够。

**Q：接口能帮我更快成交吗？**
不能。撮合 700ms 一个 tick，成交价取对手方挂单价，所有人都一样。接口省的是"手"，不是"速度"。

**Q：我策略写错了，下了很多单怎么办？**
先停策略 → 用接口或游戏撤掉在途委托 → 撤销 Key 阻止后续调用。已经成交的单不会回滚。

**Q：可以用 Key 登录游戏网页吗？**
不能，也不该。网页登录和 API Key 是两条互不认可的链路：Key 打不开 `/api/*`，网页会话也打不开 `/open/v1/*`。

**Q：我写的策略亏损了，能回档吗？**
不能。这是模拟盘，成交即定。请先用 `DRY_RUN` 模式跑通再上真单。

## 12. 最小验证脚本（Python，零依赖）

把下面存成 `check.py`，设好两个环境变量后运行。看到"全部通过"就可以开始写策略了。

```python
import json
import os
import urllib.error
import urllib.request

BASE = os.environ.get("GUSHEN_BASE", "http://127.0.0.1:3000").rstrip("/")
KEY = os.environ.get("GUSHEN_API_KEY", "")


def get(path):
    req = urllib.request.Request(BASE + path, headers={"X-API-Key": KEY})
    try:
        with urllib.request.urlopen(req, timeout=8) as r:
            return r.status, json.loads(r.read().decode("utf-8"))
    except urllib.error.HTTPError as e:
        return e.code, json.loads(e.read().decode("utf-8"))


def main():
    if not KEY.startswith("gs_"):
        print("环境变量 GUSHEN_API_KEY 没设置，或不是 gs_ 开头")
        return

    status, ping = get("/open/v1/ping")
    if status != 200 or not ping.get("ok"):
        print("鉴权失败：", status, ping.get("error"))
        return
    print("① 鉴权通过：账号 %s（%s），权限 %s，KeyID %s"
          % (ping["account"], ping.get("nick"), ping["scopes"], ping["keyId"]))

    status, meta = get("/open/v1/meta")
    if status != 200:
        print("读规则失败：", status, meta.get("error"))
        return
    print("② 规则：冷却 %dms，费率 %s，锁仓 %dms，%d 只股票"
          % (meta["rules"]["cooldownMs"], meta["rules"]["feeRate"],
             meta["rules"]["lockMs"], len(meta["stocks"])))
    print("   当前时段：%s（trading=%s）"
          % (meta["day"]["label"], meta["day"]["trading"]))

    status, acc = get("/open/v1/account")
    if status != 200:
        print("读账户失败：", status, acc.get("error"))
        return
    print("③ 账户：现金 %.2f，权益 %.2f，持仓 %d 只"
          % (acc["cash"], acc["equity"], len(acc.get("positions", []))))

    print("\n全部通过。接下来看 Doc/开放平台API.md 第 2 节跑第一个下单。")


if __name__ == "__main__":
    main()
```

运行：

```bash
python check.py
```

预期输出：

```
① 鉴权通过：账号 quant_a（量化甲），权限 read,trade，KeyID 3f2a9c1e
② 规则：冷却 2000ms，费率 0.0001，锁仓 10000ms，10 只股票
   当前时段：上午连续竞价（trading=true）
③ 账户：现金 1000000.00，权益 1002340.50，持仓 2 只

全部通过。接下来看 Doc/开放平台API.md 第 2 节跑第一个下单。
```
