## 1. 项目概述

单机可玩的**炒股模拟游戏**（「我是股神」）：玩家免密登录后，在一只模拟股上做多/做空，与 NPC 共用订单簿撮合；行情由服务端 NPC 做市引擎驱动（趋势阶段 + 消息 + 动量），支持融资/融券、爆仓强平、自动化策略、排行榜。

- **技术形态**：纯 H5 前端（无构建）+ Node.js 原生 http 服务端，REST 写操作 + SSE 推送，SQLite 存档。
- **无外部数据库 / 无 WebSocket / 无前端框架**。依赖仅 `log4js` + `better-sqlite3`。
- 默认监听 `0.0.0.0:3000`（`PORT` 环境变量覆盖）。

```
浏览器 Client（H5）
   │  POST /api/*（Bearer token）        GET /api/events（SSE，每 700ms 一帧 state）
   ▼
Server/index.js ── createServer(game) → src/http.js
   │                      │ 静态托管 Client/{index.html,app.js,style.css}
   │                      └ SSE Hub：每 tick 广播完整 state（市场共享段 + 按 token 拼账户段）
   └─ Game（src/game.js）主循环 700ms/tick
         ├ news.maybeEmit   随机利多/利空（20~60s 一条）
         ├ npc.step          公允价值/趋势 → 报价 + 主动吃单  ← 价格在这里产生
         ├ market 撮合       订单簿成交、结算、强平扫描
         ├ auto.step         玩家自动化策略（止盈止损/网格/均线/定投）
         ├ 融券/融资利息按 tick 计提
         ├ SSE broadcast
         └ persist.commit    每 tick 一个 SQLite 事务
```

**价格从哪来**：`npc.js` 维护共享公允价值 `fairValue`（趋势段随机推力 + 消息推力 + 噪声 + 向最新价/重心回归）→ NPC 据此挂双边限价单并主动吃单 → `market.js` 撮合，**成交价 = 被动方挂单价**，更新 `lastPrice`。market 不生成价格，只做撮合与风控。

## 3. 交易规则与关键默认值（`src/config.js`）

改配置只在 `require` 时读一次，**改完必须重启**。

| 项 | 值 | 位置 |
|---|---|---|
| 股票 | 600001 大米集团，流通 1 亿股，开盘 20 元，每手 100 股 | `stocks` |
| 初始资金 | 10 万元；账号上限 5000；加钱终身上限 1 亿 | `account` |
| 手续费 | 万分之一（无最低 5 元） | `trade.feeRate` |
| 下单冷却 | 同一玩家 2 秒 | `trade.cooldownMs` |
| 买入锁仓 | **T+2 分钟**（按成交时间，非自然日） | `trade.lockMs` |
| 委托价偏离 | 相对最新价 ±50% 拒单（NPC/强平豁免） | `trade.maxDeviation` |
| 价格笼子 | 单笔成交价相对上一笔 ±5%（`cagePct`） | `trade` |
| 做空保证金 | 冻结 = 市值 × 50%；维持率 30% 爆仓；强平滑点 0.5% | `margin` |
| 裸空 | 默认禁止（`allowNakedShort: false`），开空必须从融券池借券 | `margin` |
| 融券池 | NPC 出借 30% 持仓；分钟息 0.01%~0.04%（紧张度上浮） | `margin.lending` |
| 融资买入 | 自备 50%（最高 2 倍）；利息与融券同档；NPC 容量系数 1.2 | `margin.finance` |
| 涨跌停 | **默认关闭**（功能保留）；开启后 ±10% 相对昨收 | `priceLimit` |
| 停牌 | 默认 5 分钟、上限 120 分钟；入口 `server.py halt/resume` | `halt` |
| 主循环 | 700ms/tick | `tickIntervalMs` |
| 行情保留 | 五档、逐笔 500 条、分时 10300 点（≈2h） | `market` |
| 限流 | login 10、order 60、deposit 10、state 240、admin 10（次/分钟/IP）；SSE 总 500、单 IP 20 | `http` |

**权益公式**（做空口径，非期货模型）：`equity = 现金 + 挂单冻结 + 空头保证金 + 多头市值 − 空头市值`（±挂借/融资负债利息挂账）。爆仓条件 `equity < maintenance × 空头市值`（多头融资侧镜像）。

**NPC 五类**（`npc.types`，holdRatio 合计=1，开服按比例瓜分全部流通盘+现金）：

| 类 | 数量 | 持仓占比 | 现金 | 特性 |
|---|---|---|---|---|
| 机构 inst | 10 | 32% | 2.2 亿 | 可做空、固定多空阵营、分歧度两态（一致↔大战） |
| 游资 hot | 6 | 8% | 4500 万 | 动量 ×1.6、主动率 0.35 |
| 大户 big | 20 | 18% | 4500 万 | 动量 ×1.15，不做空 |
| 中户 mid | 60 | 25% | 3000 万 | 动量 ×1.2 |
| 散户 small | 220 | 17% | 1500 万 | 动量 ×1.25 |

**行情模型（趋势阶段，2026-10 起）**：大级别由「趋势阶段」驱动——时长指数分布（均值 260 tick，无记忆）、方向每次 50/50 抽签、幅度三档混合（温和 62% / 强 30% / 极端 8%，极端段可数倍或腰斩）。公允价值对数空间推进，安全边界 0.05×~20× 只是保险丝、不做触轨反转偏置。报价中枢 = 0.4×最新价 + 0.6×FV，硬夹最新价 ±3%（保证盘口始终可成交）。**`fairValue`/`fund`/`regime` 绝不能下发客户端。**

**消息**：20~60s 一条，作用 60s；scope 分 机构/散户/全体；双通道作用——情绪（偏移报价中枢、触发吃单）+ 直接乘性推公允价值（`fvDriftCoef: 0.0015`）；方向随牛熊阶段 70/30 偏置（`regimeBias: 0.2`）。

**自动化策略（auto.js）**：玩家自设、服务端每 tick 代执行（下线也跑），走 `market.place` 正常下单无后门。四类：止盈止损 / 网格（间距 0.3%~20%、≤50 格）/ 双均线 / 定投（间隔 ≥5s）。单账户 ≤20 个（含已完成）。

## 4. 服务端模块（`Server/src/`）

| 文件 | 职责 | 关键导出 |
|---|---|---|
| `config.js` | 全局配置单例，环境变量：`PORT`/`LOG_LEVEL`/`PERSIST`/`PERSIST_FILE`/`ADMIN_TOKEN_FILE` | `module.exports` |
| `logger.js` | log4js **仅 stdout** appender；落盘/轮转归 server.py。禁止 console.*（test/ 除外） | `logger`, `getLogger` |
| `db.js` | SQLite 连接（WAL + synchronous=NORMAL）、DDL、旧档补列迁移、`SCHEMA_VERSION` 校验 | `openDatabase` |
| `store.js` | 内存账户模型：现金/冻结/保证金/多空批次 lots（FIFO）、权益计算 | `Account`, `Store` |
| `orderbook.js` | 限价簿，价格优先时间优先，五档聚合 | `OrderBook` |
| `market.js` | **撮合与风控**：place 校验（停牌/整手/冷却/偏离/笼子）、match/execute/结算、融券池与融资利息、强平（含 SYSTEM 兜底）、停牌 | `Market`, `ACTIONS` |
| `npc.js` | **做市引擎**：公允价值/趋势/机构分歧度/动量情绪、重报价、主动吃单、流动性回收（地板 4200 万） | `NpcManager` |
| `news.js` | 随机消息系统 | `NewsSystem` |
| `auto.js` | 玩家自动化策略 | `AutoManager` |
| `game.js` | **门面 + 主循环**：tick 编排、login/order/cancel/lend/auto/deposit/halt 玩家 API、stateFor 快照、排行榜、前十大股东 | `Game` |
| `persist.js` | 落盘：脏标记 → 每 tick 一个事务 commit；300 tick 全量 sweep 兜底；NPC 报价单不落盘 | `Persister` |
| `http.js` | 原生 http：静态托管、CSP、限流、guardWrite（同源+JSON）、SSE Hub、全部路由 | `createServer` |
| `admin.js` | 运维口令：env→`data/admin.token`→生成；timingSafeEqual 校验 | `loadToken`, `authorized` |

**tick 顺序**（`game.js tick()`）：停牌过期 → news → npc.step → 全账户 maybeLiquidate → auto.step → 融券/融资利息 → 空头 5min 采样 → 分时入列 → refreshStats → SSE 广播 → persist.commit。

**持久化要点**（改资金/持仓路径必读）：
- 任何改钱/持仓的路径必须 `journal.touch(account)` / `orderChanged(order)` 落脏标，漏标只能靠 300 tick sweep 兜底。
- NPC 报价单**不落盘**（写 NPC 账户时退回冻结、reserved 归零），重启由 `npc.step()` 重报；落盘会产生撤不掉的幽灵单。
- 恢复走 `game.applySnapshot()`；**绝不能调 `npc.init()`**（那是新局建仓）。`fairValue`/`fund`/机构情绪态不落盘，重启重锚。
- 强平前必须撤该账户全部平仓挂单；结算按**实际成交量**入账（账实一致不变量，详见 MEMORY）。
- Windows 下 `server.py stop` 是 `taskkill /F`，**SIGTERM 钩子不会执行**——退出时不做落盘，全靠按 tick 增量写。

## 5. HTTP API（`http.js`）

写接口要求 `Content-Type: application/json` + 同源 Origin + IP 限流；身份只认 **token**（`Authorization: Bearer`，SSE 用 `?token=`）。请求体里的 `name` 不是身份来源。

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | `/api/login` | `{name}` 按名字建号/登录（同名复用、不独占），返回 token |
| GET | `/api/state` | 完整快照（含 priceHistory） |
| POST | `/api/order` | `{action, qty, price, finance}`；action ∈ buy_open / sell_close / sell_open / buy_close |
| POST | `/api/cancel` | `{orderId}` |
| POST | `/api/auto` | `{op: create/update/remove, ...}` 策略 |
| POST | `/api/lend` | `{op: lend/unlend, qty}` 融券挂借/撤借 |
| POST | `/api/deposit` | `{amount}` 加钱（受终身上限） |
| GET | `/api/events` | SSE，`event: state` 每 tick 一帧；15s 心跳；token 失效客户端自动重登 |
| POST | `/api/admin/halt` | `{minutes, reason}` 停牌，头 `X-Admin-Token` |
| POST | `/api/admin/resume` | 复牌 |
| GET | `/` `/index.html` `/app.js` `/style.css` | 静态客户端 |

每账户最多保留 5 个会话令牌（`MAX_SESSIONS_PER_ACCOUNT`）。

## 7. 客户端（`Client/`）

- **通信**：无轮询。首屏 `GET /api/state` → `EventSource('/api/events')` 每 700ms 全量重渲染；另 200ms UI 定时器只做倒计时/时钟等本地展示。localStorage 仅 `gushen_name`、`gushen_token`。
- **视图**：主页（行情列表迷你走势/资产/持仓/排行/消息）+ 交易终端（分时三带图：价格+均价/成交量/MACD(12,26,9)、五档、逐笔、下单面板、8 个标签页）。
- **交易操作**：四方向按钮（买开/卖平/卖开/买平）+ 融资勾选 + 撤单 + 挂借/撤借 + 加钱 + 自动化 CRUD。无可借券源时开空按钮禁用。
- **安全约定**：CSP 无 `unsafe-inline`——**app.js 严禁内联 `style=` 属性**，样式写 style.css 用 class；服务端字符串插 HTML 前必须过 `esc()`。
- **视觉**：深色终端 `#0b0e14`，涨红跌绿（A 股配色），等宽数字，≤860px 移动端适配。
- **布局坑**：`.main` 必须 `grid-template-rows: minmax(0,1fr)` + overflow hidden，否则画布把行撑爆导致分时图溢出。
