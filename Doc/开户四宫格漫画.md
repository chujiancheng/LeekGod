## 接入状态（2026-10-17 已实现）

**已接进开户流程**，不用再动手：

1. **触发点**：`Client/app.js` 的 `showLoginStep(2)` —— 玩家点「登录」、服务端回 `needOnboard` 后，先播漫画，播完 / 跳过后才聚焦昵称框。
2. **随机**：`pickComic()` 优先播 `gushen_comic_seen` 里没看过的套，四套轮完清空重来——纯随机会出现连着两次同一套。`comicPlayed` 只锁本次页面会话（「换账号」来回不重播）。
3. **排版**：2×2 宫格 + 每格字幕（说话人 + 台词），逐格淡入、台词 45ms/字，第 4 格播完亮出「开始开户」；「跳过 ›」与 Esc 直接进表单；`prefers-reduced-motion` 时四格一次摊开。
4. **图**：上站的是 `Client/img/comic-<set><n>.png`（512px，16 张，4.6MB 总量、每次只加载 4 张）；1024 母版在 `art/onboarding-comic/`。`http.js` 的 `IMG_ASSETS` 有独立注册块，**换名/加套必须同步登记，否则裂图**。
5. **改文案**：只改 `Client/app.js` 的 `COMICS` 表，图不用重画；只有换画面时才需要重画对应格，然后跑 `art/onboarding-comic/build_web_assets.py` 重出 512 图。
6. **自检**：`Client/test/client-day.test.js` 的 `[18]` 段（宫格数量、16 张图是否存在、跳过收场、四套轮播不重复、回看模式）。

### 复看入口（2026-10-17 追加）

主页 hero 区的「看漫画」按钮（`#comicReplayBtn`）→ `openComic(null, true)` 进**回看模式**，与开户过场共用同一个 `#comicOverlay`，靠 `comicReplay` 这个开关分措辞和行为：

| | 开户过场（`replay=false`） | 首页回看（`replay=true`） |
|---|---|---|
| 抬头 | 开户前，先看个故事 | 开户漫画 · 四套随便翻 |
| 右上按钮 | 跳过 › | 关闭 |
| 四套切换片 | **不显示**（随机哪套看哪套，别让人先挑） | 显示 A · 起点 / B · 门派 / C · 第一课 / D · 挑战 |
| 播完的按钮 | 开始开户（点了收场并聚焦昵称） | 下一套 ›（点了换下一套，不关层；A→B→C→D→A 循环） |
| 进度行 | `2 / 4 格` | `第 2 / 4 套 · 2 / 4 格` |

- 换套走 `switchComic(id)`：停掉当前计时器、重绘宫格、重新播；高亮跟着 `renderComicSets()` 走。
- 回看**不写 `comicPlayed`**（那是开户流程的一次性锁），所以开户该播还是会播。
- `closeComic()` 会把 `comicReplay` 复位、清空切换片——否则下次开户过场会带着「关闭」和四个切换片进来。
- 新增一套故事时除了 `COMICS` 表和图片注册，记得补 `short`（切换片的短名，2~3 字最好，长了在手机上会折行）。

7. **后续彩蛋**：D3 的「泪痕锦旗」可与彩蛋系统的爆仓称号呼应——玩家爆仓时猫送同款锦旗。
8. **合规**：台词未出现真实公司名；B2 里的券商谐音名与现有配置一致，若券商名单调整需同步改这格文案。
